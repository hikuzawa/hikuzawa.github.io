ゆいまる

ご近所の助け合いが、地域への支援にめぐるアプリ／プライバシーポリシー

「ゆいまる」（以下「本アプリ」）における個人情報の取り扱いについて定めます。最終更新日: 2026年9月5日

1. 取得する情報

本アプリは、次の情報を取得します。

  • 電話番号 … ログインと本人確認のため
  • お名前 … 依頼のやり取りで相手に表示するため
  • 年代・お住まいの地域（町名まで） … 依頼を探すため、相手が安心するため
  • 自己紹介文 … プロフィールに表示するため
  • 本人確認の書類の画像 … ご本人であることを確かめるため
  • 作業場所の住所 … 依頼が成立した相手にだけ伝えるため
  • 作業の写真 … 完了報告のため
  • メッセージの内容 … 利用者どうしの連絡のため
  • 評価・レビュー … 安心して依頼できるようにするため
  • 端末の通知トークン … お知らせを届けるため

位置情報を継続的に取得することはありません。連絡先（アドレス帳）にもアクセスしません。広告のための情報収集は行いません。

2. 保管する場所

日本国内（Google Cloud 東京リージョン）のサーバーに保管します。国外への移転は行いません。

3. 消去について

次のものは、一定期間で自動的に消えます。

  • 詳しい住所の表示 … 依頼の完了から72時間で見えなくなります
  • 作業の写真 … 30日で削除されます
  • 通話のやり取りの記録 … 通話の終了後すぐに削除されます。映像と音声は端末どうしが直接やり取りするため、サーバーには残りません

退会をご希望の場合は、下記の連絡先までご連絡ください。アカウントと関連する情報を削除します。ただし、取引の記録のうち法令で保存が必要なものは、必要な期間だけ保持することがあります。

4. 第三者への提供

ご本人の同意なく、第三者へ提供することはありません。ただし、法令に基づく場合、および人の生命・身体・財産の保護のために必要でご本人の同意を得ることが難しい場合を除きます。

本アプリの運営のために、次の外部サービスを利用しています。

  • Google Cloud Japan … サーバーとデータベースの提供

5. 安全管理

  • 通信はすべて暗号化しています
  • 写真のファイル名は推測できない乱数にし、一覧を公開していません
  • 本人確認の書類は、確認の担当者のみが閲覧します
